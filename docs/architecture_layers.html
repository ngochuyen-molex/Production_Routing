3. One run, in order

  1. Read - workbook.rows() gives the Excel rows.
  2. Parse - each row becomes a Request; bad rows become InvalidRow; deletes are sorted first.
  3. Previous results - existing RESULT_* columns are read back, so a rerun skips finished steps.
  4. Context - opened once; Snowflake on first use, SAP only when a SAP step runs (never in --dry-run).
  5. Plan (Snowflake only) - all routings + material status loaded in one batch; every step.plan() fills row.plan (target, copy source, layout, alt BOMs, skip reason, warnings). Plan sheet written. --dry-run stops here.
  6. Execute - phase by phase (routing -> components -> pv), every row, every step: skip if done, write Skipped / Failed from the plan, else safe_run() -> step.run(). Any error: SAP screen read, SAP reset without saving, step = Failed, next row continues. File saved after every row.
